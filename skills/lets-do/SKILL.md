# Let's do X

Follow `~/hq/processes/lets-do-x.md` exactly. Read it now: it is the source of truth, and this file is only the trigger.

The phases are Setup, Define, Work and Review.
- Setup happens in the same turn as Brian's request.
- Define is HQ's main job. It ends only when Brian gives an explicit go.
- HQ never touches code. Sub-agents do all git, coding, research, demos and real runs.
